# ADAPTIVE AI–NWP MULTI-MODEL FORECAST BLENDING SYSTEM

SIH 2026 — PS 26081

This repository contains the codebase for an adaptive multi-model weather forecast blending system.

## Project Structure
- `configs/`: Experiment configurations
- `data/`: Data manifest and small sample data (DO NOT commit large datasets)
- `docs/`: Project documentation and records
- `logs/`: Execution and training logs
- `artifacts/`: Model weights, training artifacts
- `reports/`: Generated metrics and reports
- `scripts/`: Utility scripts
- `src/`: Main source code package (`blend`)
- `tests/`: Unit and integration tests
