# Architecture

The system is an adaptive multi-model weather forecast blending system.

## Pipeline
1. Forecast Sources
2. Data Standardization
3. Common Grid / Time Alignment
4. Quality Control
5. Bias Correction
6. Historical Skill Engine
7. Context Engine
8. Adaptive Model-Trust / Gating Model
9. Dynamic Forecast Weights
10. Blended Forecast
11. Probabilistic / Uncertainty Layer
12. Separate Extreme-Event Pathway
13. Verification
14. API
15. Dashboard
